## Install

Run in your terminal. Requires [uv](https://docs.astral.sh/uv/getting-started/installation/) and Python 3.10+.

<Terminal title="terminal" command={"uv tool install --upgrade selvedge\nselvedge --version"} copy kind="install" />

<p class="quickstart-release">Current release: <a href={product.changelogUrl}>Selvedge {product.version}</a>.</p>

<details>
<summary>Use pip instead</summary>

Install in a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade selvedge
```

On Windows, activate with `.venv\Scripts\Activate.ps1` in PowerShell. If your system calls Python `python3`, use that to create the environment. Start your editor from the activated terminal, or use the absolute path to `selvedge-server` in its MCP configuration.

</details>

<details>
<summary>Try a demo first</summary>

```bash
selvedge demo
```

The demo saves a rejected approach and retrieves it through a fresh connection to a temporary database. It does not write to your project. The demo requires Selvedge 0.3.12 or newer.

</details>

## Save one decision

Paste this into your connected coding agent:

<Terminal title="paste into your agent" command="Use Selvedge to save one real decision from this project, including why we made it and any approach we rejected. Ask me if no decision is available; do not invent one. Show me the saved entity path and record ID." copy kind="prompt" />

Open a **new session in the same project**. Give your agent the saved entity path and ask it to retrieve the decision with `prior_attempts`. Check that the result matches what you saved.

Only decisions explicitly saved to Selvedge can be recalled.

## Need a hand?

<details id="if-nothing-appears">
<summary>My agent cannot find Selvedge or my saved decision</summary>

1. Run `selvedge doctor` and [check your version](/upgrade/).
2. Confirm `selvedge-server` is on your agent’s PATH. With uv, run `uv tool update-shell`, then restart your terminal and editor.
3. Restart your agent in this project and enable Selvedge’s tools. Codex needs a trusted project; Copilot uses VS Code Local in Agent mode.
4. Confirm both sessions use the [same project database](/reference/configuration/#db-path-resolution).
5. Ask the agent explicitly to use `log_change`, then look up the saved entity with `prior_attempts`.

Native lifecycle adapters are available for all six agents; capabilities and activation differ. [Activate and verify your agent’s hooks](/guides/agent-lifecycle-hooks/).

</details>

<details id="read-your-project-history">
<summary>Use the CLI to read history</summary>

```bash
selvedge status
selvedge prior-attempts users.api_key
selvedge history --since 7d
selvedge search "credentials"
```

Replace `users.api_key` with your saved entity path. Read commands support `--json`. See the [CLI reference](/reference/cli/), [MCP tools](/reference/mcp-tools/), and [entity path guide](/reference/entity-paths/).

</details>

<details id="unattended-setup">
<summary>Connect multiple agents or automate setup</summary>

Repeat `--agent` to connect several tools to one project. Without it, setup detects supported tools. Custom MCP entries raise a conflict; custom Codex TOML entries need manual reconciliation. `--force` never rewrites those entries.

For unattended setup:

```bash
selvedge setup --agent codex --non-interactive --yes
```

Without `--yes`, non-interactive setup is a dry run.

</details>
